Layer Opacity Control

Version 1.1.0 | A Krita Extension for efficient opacity management.

📖 Overview

Layer Opacity Control allows you to quickly increase or decrease the opacity of the currently selected layer or group using keyboard shortcuts. This eliminates the need to manually adjust the opacity slider for every small change.

🚀 Getting Started

  1. Enable the plugin in Settings → Configure Krita → Python Plugin Manager.
  2. Restart Krita to apply the changes.
  3. Configure your preferred shortcuts in Settings → Configure Krita → Keyboard Shortcuts. Search for "Layer Opacity Control" to find the actions.

⌨️ Usage

Select any paint layer, vector layer, or group layer in the layer stack and use your assigned shortcuts to adjust the opacity.

Configuring the Increment

You can change how much the opacity changes with each press. Go to Tools → Scripts → Configure Opacity Increment to set a value between 1 and 255.

🐛 Troubleshooting

Action is grayed out: If the script is disabled when selecting a group, ensure you are using the latest version of the plugin which sets activationFlags to 0.

📘 Note on Group Layers: This plugin supports both Normal and Pass-through groups. If a Pass-through group is selected, the plugin will automatically convert it to a Normal group to ensure the opacity change is visible on the canvas.
