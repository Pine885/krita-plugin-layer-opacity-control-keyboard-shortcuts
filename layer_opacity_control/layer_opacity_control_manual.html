Layer Opacity Control (v1.2)

Version 1.2.0 | A Krita Extension for efficient opacity management (★ω★).

Overview (・ω・)

Layer Opacity Control allows you to quickly adjust layer opacity using keyboard shortcuts.

Getting Started (o^▽^o)

  1. Enable the plugin in Settings → Configure Krita → Python Plugin Manager.
  2. Restart Krita to apply changes.
  3. Configure shortcuts in Settings → Configure Krita → Keyboard Shortcuts.

Usage (｡♥‿♥｡)

Select any paint layer, vector layer, or group layer and use assigned shortcuts.

Configuring the Increment

Go to Tools → Scripts → Configure Opacity Increment to set a value between 1 and 255.

Troubleshooting (o_O)

Action is grayed out: Ensure you are using the latest version with automatic action setup.

Note on Group Layers: Supports Normal and Pass-through groups. Pass-through groups are automatically converted to Normal groups when opacity changes.
